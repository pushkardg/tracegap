Defects found, with fixes

Each fix has a regression test that fails before and passes after, and the TraceGap scenarios listed pass on the patched framework.

ProjectDefectScenarios
OpenAI Agents SDKA tool interrupted by run cancellation closes its function span with no error, so it reads as a success.S17
AutoGenrun() hangs after a CancellationToken cancel during a tool; the in-flight tool keeps running after the run task is cancelled; the cancelled tool's span is left unset.S17
Semantic KernelA cancelled function's execute_tool span is left unset (successful-looking).S17
Google ADKA cancelled tool's span is left unset, including siblings ADK cancels after one parallel call fails.S07, S17
smolagentsA step's memory records no tool calls when any call in it fails; duplicate call ids are silently dropped.S05–S07, S11

Shared cause of the cancellation spans: OpenTelemetry's use_span records only Exception, and asyncio.CancelledError is a BaseException.

Across releases

The core suite was run against 65 past releases, with each release's dependencies resolved as of its release date. Highlights:

  • smolagents' memory loss arrived with parallel tool calls in 1.18.0; silent dropping of duplicate call ids in 1.20.0.
  • The OpenAI Agents SDK started rejecting duplicate call ids in 0.20.0 and redacting tool errors from spans in 0.23.
  • Pydantic AI's OpenTelemetry spans started showing rejected calls in 2.30.0.
